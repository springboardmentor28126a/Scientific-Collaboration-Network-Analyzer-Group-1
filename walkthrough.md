# Collaboration, Citation, and Notification Walkthrough

## 1. Registration and login
1. Open the app and create a new researcher account.
2. Sign in with the new account and confirm the dashboard loads.

## 2. Collaboration workflow
1. Navigate to Collaborations.
2. Create or open a project.
3. Send an invitation to another researcher.
4. Accept or reject the invitation from the recipient account.
5. Confirm the request status updates and the project membership changes when accepted.

## 3. Citation and reference workflow
1. Open a publication from the Publications page.
2. Go to the References tab and add a new reference.
3. Switch to the Citations tab and link the publication to another publication.
4. Confirm the citation count updates on the publication detail view and list view.

## 4. Notifications
1. Trigger a collaboration request or citation event.
2. Confirm a live toast appears and the notifications page shows the new item.
3. Mark notifications as read and confirm the unread badge updates.
