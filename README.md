# Scientific-Collaboration-Network-Analyzer-Group-1# Scientific Collaboration Network Analyzer

## Overview

Scientific Collaboration Network Analyzer is a research collaboration management platform developed using FastAPI and PostgreSQL. It enables universities and research organizations to manage researchers, institutions, publications, conferences, projects, collaborations, and citations.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
