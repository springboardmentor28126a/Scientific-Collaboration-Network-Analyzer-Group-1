# Scientific Collaboration Network Analyzer

## Project Overview

The Scientific Collaboration Network Analyzer is a web application developed to manage researchers, publications, conferences, projects, institutions, collaborations, and peer reviews.

## Technologies Used

- FastAPI
- ReactJS
- PostgreSQL
- SQLAlchemy
- Bootstrap
- Git & GitHub

## Features

- User Registration and Login
- Researcher Management
- Publication Management
- Conference Management
- Project Management
- Collaboration Management
- Institution Management
- Reviewer Dashboard
- Review Queue
- File Upload
